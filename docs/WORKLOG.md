**النطاق:** ملفات المعرفة والتنسيق + هيكل Next.js + i18n + Prisma/SQLite + مصادقة + RBAC + لوحة تحكم أساسية + CI + الرفع إلى GitHub.

**ما نُفّذ:**

- اعتماد قرار البنية: تطبيق Next.js 16 موحّد (لوحة + API) + SQLite/Prisma + نشر Vercel + نفق Cloudflare + خادم محلي Termux — موثّق في AGENTS §0.
- مخطط Prisma للمرحلتين 0–1: شركات/عضويات/أدوار/منح محاسب/تدقيق/إعدادات/سياسات تحقق/قواعد أجور + `sessionsInvalidatedAt` للإبطال الحقيقي للجلسات.
- i18n داخلي: قواميس ar/fr/en/es + RTL + مبدّل لغة عبر Server Action — لا نصوص ثابتة في الكود.
- مصادقة JWT (httpOnly) + جلسة بشركة نشطة + تبديل شركة مسجّل في التدقيق + إبطال حقيقي للجلسات عند الخروج.
- RBAC خادمي بطبقة واحدة + حماية مسارات لوحة/API (اختبار E2E: عامل ← 403 على التدقيق؛ عزل الشركات يعمل).
- صفحة هبوط `/` + لوحة `/dashboard` بحسب الدور + `/api/health` + `/api/auth/*` + `/api/audit`.
- GitHub Actions (lint + build) + `.env.example` + عناصر `infra/` + شعار FWMS (favicon).
- بذور أولية: مالك منصة + شركة تجريبية + 5 مستخدمين بأدوارهم الخمسة (كلمة المرور التجريبية موثّقة داخل البذور).
- تحقق كامل بالمتصفح الآلي: هبوط RTL، تبديل لغات (ar↔fr) مع تغيّر الاتجاه، دخول، لوحة ببيانات حقيقية، خروج.
- **شفافية git:** أول رفع حمل سهواً التزام القالب الأصلي (كان يتضمن `.env` بلا أسرار لكنه غير نظيف)؛ صُحّح بدفع قسري لالتزام نظيف واحد + وسم v0.1.0 صحيح + إزالة بقايا القالب (download/ وmini-services/). المستودع الآن بلا أي ملف بيئة أو سر (تحقق عبر API).
