## [2026-10-16] — المساعد الثاني: تأسيس قاعدة البيانات المحلية + النفق الدائم

**النطاق:** تهيئة البيئة على Samsung A53 (Termux/Ubuntu PRoot) + migration أساسي + بذور قواعد الأجور + نسخ احتياطي/استعادة + نفق Cloudflare موحّد + مراجعة مخطط المرحلة 2.

**ما نُفّذ:**
- **البيئة:** `npm install` (853 حزمة؛ أول محاولة انتهت بمهلة 10 دقائق وأُعيدت في الخلفية) + `bun 1.4.3` (كان ناقصًا — مسار مدعوم في DATABASE_GUIDE §2.2) + `sqlite3 3.46.1` + `cron`.
- **المخطط:** راجعتُ واعتمدتُ تغييرات المرحلة 2 (`Branch`/`Project`/`Site`/`WorkerGroup` + ربط `VerificationPolicy.siteId`) — متوافقة مع القواعد النافذة. طُبّق كـ **migration أساسي** `20261016182538_init_baseline` → 13 جدولاً على `db/fwms.db`.
- **بذور الأجور (§6):** `prisma/seeds/pay-rules.ts` — 24 قاعدة من SPEC §11 بتواريخ سريان ومصادر؛ النسب bp أساس 10000؛ `ir.brackets` JSON (6 شرائح شهري+سنوي)؛ `verifiedBy=null`؛ idempotent؛ مُوصولة بـ `seed.ts` (استيراد + استدعاء فقط).
- **تشغيل محلي:** بناء إنتاج ناجح (`next build` → standalone) + خادم على 0.0.0.0:3000 → `/` 200 و`/api/health` `{"status":"ok","database":"ok","version":"0.2.0"}`.
- **نسخ احتياطي (§7):** `backup-db.sh` (Backup API + `PRAGMA quick_check` + عدّ جداول + دوران 7/4/6 بلاحقة نوع النسخة) + `restore-db-test.sh` (استعادة فعلية للمقارنة البنيوية) + غلاف توافق لـ `backup.sh` القديم + **cron يومي 03:15 مع flock** (سطر موثّق ومُختبَر يدويًا) + `service cron start` داخل `start-server.sh`.
- **النفق:** إنشاء نفق موحّد `fwms-phone` (حساب 758fcc…، id `6667afcf-e867-4dc4-9deb-f1f08b1df803`) — التوكن في `.env` (متجاهَل) + `run-tunnel.sh` + تشغيل تلقائي مع الخادم. **الاستقرار:** QUIC/UDP مقيّد في أندرويد/PRoot (تذبذب connIndex) → إجبار `--protocol http2` → 4 اتصالات مستقرة صفر أخطاء.

**ما نُفّذ من اختبارات:**
- `prisma db seed` مرتين → 24 قاعدة بلا تكرار (idempotent مثبت)؛ `PRAGMA` للشرائح يُحلّل بستة شرائح آخرها 370000 bp.
- نسخة احتياطية 208K → فحص سلامة ok + 14 جدولاً؛ استعادة: 13 جدولاً مطابقاً سطراً بسطر (Company=1، User=5، PayRule=24…).
- إصلاحان موثّقان أثناء التحقق (راجع KNOWLEDGE_BASE §9): بناء sqlite3 هذا بلا `.quick_check`؛ `_` في LIKE يستبعد كل الجداول.

**ما تبقى (خارطة المساعد الثاني):**
- **سؤال موجَّه لصاحب المشروع (عالية):** التوجيه العام للنفق يحتاج نطاقًا على حساب 758fcc… — لا يوجد نطاق في الحسابين حاليًا (فحص API: صفر zones). بدونه: النفق يعمل لكن بلا عنوان URL عام ثابت.
- اختبار الاستعادة الأسبوعي المجدول (يدعمه السكربت — يُوثَّق كل تشغيل في `backup.log`).
- مراجعة `pay_rules` من المحاسب (كل السطور `verifiedBy=null` عمدًا).
